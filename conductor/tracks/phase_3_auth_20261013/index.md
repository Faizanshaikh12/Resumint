# Track: Phase 3 - Authentication

## Overview
This track implements the authentication layer for Resumint using Better Auth with Cloudflare D1 (Drizzle SQLite adapter) on Cloudflare Workers. It establishes edge-compliant password hashing, route guards, reusable `AuthForm` UI, rate limiting, and verifies performance under the 10ms CPU free-tier budget with live deployed benchmarks.
